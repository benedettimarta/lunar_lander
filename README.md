# AE4350_assignment
Deep Reinforcement Learning for Autonomous Lunar Landing

## Installation
pip install -r requirements.txt

## Run order

1. Train one baseline agent: 01_train_baseline.py

2. Evaluate the baseline: 02_evaluate_model.py

3. Run sensitivity analysis: 03_run_sensitivity_analysis.py

4. Generate figures: 04_plot_results.py

5. Watch the trained agent: 05_watch_trained_agent.py

## Output folders

- `models/`: trained models
- `logs/`: training reward logs
- `results/`: evaluation metrics and sensitivity summary
- `figures/`: PNG plots for the report
